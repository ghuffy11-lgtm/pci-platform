C. THE PRE-REGISTERED VERDICT RULE -- stated BEFORE any result is seen
==============================================================================
  Group every L4 / W-B cell by its MEASURED residue, not by its target:
  
      SCARCE     1 <= residue <= 2     (TASK-0048 measured 1)
      PLENTIFUL  residue >= 10     (TASK-0046 measured 10)
      ZERO       residue = 0        (the specificity control; excluded from the rule)
      MIDDLE     otherwise          (reported, and not used by the rule)
  
  Let rSCARCE and rPLENTIFUL be the proportion of cells in each band carrying a
  history-sourced finding.  Then:
  
      CONFIRMED   iff rPLENTIFUL > 0 AND rSCARCE = 0
                      -- the leak appears when residue is plentiful and is absent
                         when it is scarce, which is exactly the pair of prior
                         results, and density explains the divergence.
  
      REFUTED     iff rPLENTIFUL = 0
                      -- a deliberately large residue population does NOT
                         reproduce the leak, so density does not explain
                         TASK-0046's finding;
                  OR  iff rSCARCE > 0 AND rSCARCE = rPLENTIFUL
                      -- the leak occurs at every density including the scarce
                         one, so density does not explain TASK-0048's silence.
  
      UNRESOLVED  in every other case, INCLUDING a partial gradient
                  (rPLENTIFUL > rSCARCE > 0) and any case where the two journal
                  modes disagree.  UNRESOLVED IS REPORTED AS UNRESOLVED.
  
  A band with no cells makes the result UNRESOLVED: a rule cannot be evaluated
  on an empty set, and NC-4 gates that case before this rule is reached.

G2. THE SAME CELLS, GROUPED BY *FREE* RESIDUE INSTEAD OF TOTAL RESIDUE
==============================================================================
  Total residue counts two mechanically different things together:
    FREE        a whole page on the free list.  Only an ALLOCATING write
                reaches it.
    CO-RESIDENT a page the successor partially reused, so live authorized
                rows and the predecessor's dead bytes share it.  A write
                that touches an authorized row on it reaches it; an
                allocating write never does, because it is not free.

  Both priors, and the pre-registered rule, count TOTAL.  This grouping is
  reported ALONGSIDE, not instead of, and it changes no verdict by itself.

               0           0/1                    0 of 8                0 of 8
               1             0                    4 of 4                0 of 4

               0           0/1                    4 of 8                4 of 8

  THE TWO MODES ARE NOT MEASURING THE SAME EXPOSURE, and the page-level
  listing in section H shows why in the cells themselves rather than by
  argument: a rollback journal records the page image BEFORE the write, so
  ANY reuse of a residue page exposes the predecessor's content in full; a
  WAL frame records the image AFTER, so a page that the write FULLY overwrote
  exposes nothing.  Compare the "page images the request made durable" lines
  for the F1 and D2 wal/W-B cells: the same page 3 is "AUTH-only" in one and
  "UNAUTH-only:x15" in the other.

H2. THE MECHANISM, EXHIBITED BY PAGE NUMBER RATHER THAN ASSERTED
==============================================================================
  §4.19 records what made TASK-0046's evidence worth promoting: the pages were
  identified, classified individually and byte-verified, so the mechanism was
  exhibited rather than re-asserted.  The same is done here, and it is what
  turns "the append consumed a residue page" from a story into a measurement.

  For each density, one representative cell of each write shape, delete mode,
