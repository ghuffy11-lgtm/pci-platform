**Two things this table establishes that neither prior record states.**

1. **Residue density is not the only variable that differed.** Four others did: the transition kind, the
   page-cache setting, the fixture proportions, and the verdict basis. **A design that varies density
   alone would produce a result that cannot distinguish density from those.**
2. **The divergence runs in BOTH directions.** The record so far describes it as *"TASK-0046 saw the
   append leak; TASK-0048 saw nothing"* — but **the same two runs also disagree in the opposite
   direction on W-A**, where TASK-0048 found what TASK-0046 did not. **That is visible only by reading
   the two outputs side by side, and it is recorded here because it widens what a "reconciliation of
   the two priors" (required outcome 6) has to account for.** **Neither prior record is re-opened,
   weakened or contradicted by this observation** — both stand exactly as taken; this says only that
   the contradiction has a second face.

### Design, stated before it is built so the result can be checked against an intention

**Primary factor — residue density**, at **four levels** (target `0`, `~1`, `~10`, `~40` residue pages).
Three is the floor the task file sets; the fourth is level `0`, which doubles as a specificity control.
The levels span **both prior fixtures** (TASK-0048's `1`, TASK-0046's `10`) as required.
**Density is achieved by a calibration sweep over predecessor size that the harness runs and reports,
and it is MEASURED per cell, never assumed.**

**Required co-factors:** journal mode (`delete`, `wal`) × write shape (`W-A` access accounting, `W-B`
append), exactly as MSG-0158 and MSG-0163 used them.

**Two DECLARED secondary factors, beyond the task file's minimum, and here is why they are in scope
rather than scope creep:** transition kind (`DROP` / `DELETE`) and page cache (default / `-8`). **These
are two of the four uncontrolled differences tabulated above.** Required outcome 6 obliges this run to
*reconcile the two priors*, and **with these held at one arbitrary level the reconciliation could not
distinguish density from them** — the conclusion would rest on an assumption the run was built to
avoid. They are declared here, reported per cell, and **the verdict rule below is stated in advance so
that including them cannot become a way to select a preferred answer afterwards.**

**Cells: 4 densities × 2 journal modes × 2 write shapes × 2 transitions × 2 cache settings = 64**, each
reporting its own measured residue count.

**The verdict rule is PRE-REGISTERED in the harness, before any result is seen**, so CONFIRMED /
REFUTED / UNRESOLVED is decided by a rule rather than by reading the numbers and choosing. Required
outcome 5 forbids rounding an unresolved result to either side, and a rule written after the fact is
exactly how that rounding happens.

**Controls GATE the run — required outcome 4, and MSG-0169 §2 is the standing correction it cites.**
The harness must `fail()` and **abort before printing any verdict** when a control does not fire.
*"A printed line is a claim; an abort is an interlock."* Planned gates: a mechanism control that must
produce a finding; an instrument control on a marker never written; a specificity control (density `0`
must produce no history-sourced finding); an independent-variable control (the achieved densities must
actually be distinct and span the required range, or the experiment measured nothing); a provenance
control (zero live unauthorized rows in every L4 cell); and a parser control (journal images
byte-identical to an independently read copy). **A control's finding is never reported as a finding
about the subject** — MSG-0156.
