**Two defects in the probe's own apparatus were found and fixed BEFORE any result was reported.**
Both are recorded in MSG-0158 §7 and in the harness's own comments rather than quietly corrected:

1. **The first parser required the rollback journal's magic bytes, and all four rollback-mode
   measurements came back `MAGIC DID NOT MATCH` and INVALID.** The cause was established rather than
   guessed: read *during* the transaction — the only time the artefact exists — bytes 0..7 are
   **zero**, because the engine writes the magic **last** so a torn journal is not mistaken for a
   complete one. The fix was not to drop the check but to **replace it with a stronger one**: every
   parsed page image is now compared byte for byte against an independently read copy of the store.
2. **A comparability check was wrong in a way that would have failed the run for being correct.** It
   asserted that no configuration had unauthorized rows *in reach* — but that figure **is the
   independent variable** (L1: 200; L2/L3/L4: 0). It was replaced with the invariant that actually
   matters and is now **measured after every write**: the number of rows the request modified that it
   was not entitled to. That is **0 in all 16 configurations**.
