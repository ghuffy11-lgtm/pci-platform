## Checkpoint 2 — ADR-0020 §§3–4 inspected; amendment judged necessary

**Written after** reading the accepted copy in full.

**Finding: the stop condition "§§3–4 already state the consequence unambiguously" does NOT apply.**
§3.1 and §4 state the *rule* — the candidate set is built "already constrained", and retrieving
broadly then filtering is a gate failure. Neither states the *consequence for engine selection*: that
a retrieval engine which cannot apply authorization constraints within the query is disqualified.
That gap is what MSG-0092 §3 asked to close, and it is real.
