## Specifications

Foundation and domain specifications must cover identity, policy, workflows, search, ingestion, enterprise knowledge, notifications, assets/configuration, monitoring, extensions, AI evaluation, agent context, human approval, change management, reporting, backup/restore, deployment, network, helpdesk, facilities, biomedical, security operations, integration, and domain extension.

## Completion Rule

The baseline is considered complete when every required artifact exists in GitHub, has an owner/status, cross-references related architecture and specifications, and is verified against the repository tree. New discoveries after baseline completion become controlled ADR/RFC/SPEC additions rather than undocumented side work.
