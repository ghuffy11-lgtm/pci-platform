# PCI Program Roadmap

**ID:** ROADMAP-0001  
**Status:** Active  
**Planning horizon:** Multi-year

## Phase 0 — Genesis

- Establish Constitution and governance.
- Establish Reality Model and Knowledge Fabric architecture.
- Establish engineering-agent rules.
- Validate standards.

## Phase 1 — Foundation

- Build repository and CI foundation.
- Build canonical knowledge services.
- Establish identity integration.
- Establish secrets/configuration management.
- Establish observability.
- Establish deployment automation.

## Phase 2 — PCI Understands PCI

- Model PCI components, dependencies, interfaces, decisions, deployments, and operational state.
- Provide knowledge queries and architecture views.
- Validate AI context retrieval against the model.

## Phase 3 — Intelligence and Agents

- Local model runtime abstraction.
- Agent orchestration.
- Governed tool execution.
- Human approval workflows.
- Evidence and audit.

## Phase 4 — Customer Zero

Use the founder's organization as the first real deployment. Prioritize real IT/network/helpdesk/facilities/biomedical use cases.

## Phase 5 — Productization

- Multi-tenant/customer isolation where required.
- Installation and upgrade automation.
- Packaging and support model.
- Enterprise security hardening.
- Documentation and operational runbooks.

## Phase 6 — Ecosystem

- Domain capabilities.
- Connector ecosystem.
- SDKs and extension points.
- Marketplace if justified.

## Rule

The roadmap is directional. Individual releases are governed by approved specifications and architecture decisions.
