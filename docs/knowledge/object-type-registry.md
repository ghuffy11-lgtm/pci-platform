## Registry Rules

New core object types require architecture review. Domain-specific types should be introduced only when existing types cannot accurately represent the domain concept.

Object types must define ownership, lifecycle, required attributes, permitted relationships, provenance requirements, and classification behavior.

The registry is intentionally extensible. It is not a promise that every customer must use every type.
