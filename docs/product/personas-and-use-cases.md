# PCI Personas and Use Cases

## IT Operator

Needs infrastructure health, incident context, topology, configuration evidence, and safe remediation.

## Network Engineer

Needs device inventory, topology, configuration analysis, proposed changes, validation, and controlled execution.

## Helpdesk Technician

Needs user context, asset context, history, knowledge, and guided resolution.

## Facilities Operator

Needs building, room, asset, maintenance, incident, and service relationships.

## Biomedical Engineer

Needs equipment identity, location, service history, calibration, maintenance, and related tickets.

## Security Administrator

Needs identity, policy, audit, risk, and authorization visibility.

## IT Manager / Executive

Needs operational status, trends, risk, workload, service health, and decision support without requiring technical detail.

## Knowledge Worker

Needs authorized access to internal documents, policies, procedures, and organizational knowledge with provenance.

## Agent / Automation

Needs machine-readable context, explicit authority, safe tools, policy evaluation, and verifiable outcomes.

## Foundational User Journeys

1. Ask a question about the organization and receive an evidence-backed answer.
2. Investigate an infrastructure issue and trace affected objects.
3. Propose and safely execute a network configuration change.
4. Correlate a helpdesk ticket with an affected asset and service.
5. Search internal knowledge while preserving access controls and provenance.
