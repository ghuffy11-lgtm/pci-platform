# PCI Operational Runbook Index

**Status:** Foundation

## Required Runbooks

- Initial installation
- Bootstrap and identity setup
- Backup
- Restore
- Health diagnosis
- Service restart
- Storage expansion
- Certificate rotation
- Secret rotation
- Model installation
- Model replacement
- Connector onboarding
- Connector disablement
- Agent emergency stop
- Network change rollback
- Security incident containment
- Upgrade
- Downgrade/rollback where supported
- Disaster recovery
- Air-gapped update
- Tenant isolation verification

## Runbook Standard

Every runbook must state prerequisites, authorization, expected impact, commands/actions, verification, rollback, evidence, and escalation conditions.

## Automation Rule

A runbook may become an automated workflow only after its safety conditions and verification steps are represented explicitly in a governed workflow specification.
