# PCI Platform

**Working Codename:** PCI

PCI is being designed as a private, modular Enterprise Intelligence Platform.

The repository is currently in **Project Genesis / Foundation**. The initial work is intentionally focused on establishing the engineering knowledge model, architecture, governance, and implementation rules before production code is introduced.

## Current Status

- Repository initialized
- Architecture governance in progress
- Engineering Knowledge System / Knowledge Fabric being designed
- Production implementation not yet started

## Source of Truth

The Git repository is the canonical engineering source of truth. Architectural decisions, specifications, standards, and implementation guidance must be represented here in structured, version-controlled form.

## Working Principle

> Model reality. Everything else follows.
