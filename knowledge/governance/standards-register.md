# PCI Standards Register

**ID:** GOV-STANDARDS-0001  
**Status:** Active

| Area | Standard | Status | Notes |
|---|---|---|---|
| Linked data | JSON-LD 1.1 | Adopt conceptually | W3C Recommendation; canonical semantics remain storage-neutral |
| Provenance | W3C PROV | Adopt concepts | Use for provenance interoperability |
| Architecture | C4 | Adopt | Preferred software architecture view model |
| API | OpenAPI | Adopt | HTTP API contract where applicable |
| Identity | OpenID Connect / OAuth 2.x | Adopt | Prefer established IdP integration |
| Observability | OpenTelemetry | Adopt | Vendor-neutral telemetry |
| AI tools/context | MCP | Evaluate/adopt where appropriate | Use current protocol revision applicable at implementation time |
| Containers | OCI | Adopt | Portable image/runtime boundary |
| Source control | Git | Adopt | Engineering source of truth |

## Governance

This register records the standards PCI prefers. It does not require every component to use every standard. Exceptions require documented rationale.

## Currency

Standards must be checked against current upstream specifications before implementation. Version numbers should be pinned in implementation specifications, not assumed from this evergreen register.
