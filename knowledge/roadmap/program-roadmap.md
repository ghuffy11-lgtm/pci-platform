# PCI Program Roadmap

**Status:** Founding Roadmap  
**Planning Horizon:** Multi-year; milestones are capability-based rather than technology-release based.

## Phase 0 — Genesis and Governance

- Constitution
- Product vision
- Architecture principles
- Knowledge object model
- Relationship taxonomy
- AI engineering rules
- ADR/RFC/SPEC governance
- Security principles

## Phase 1 — PCI Foundation

- Ubuntu host baseline
- Container/runtime strategy
- Storage and backup strategy
- Identity and access management
- Secrets management
- Reverse proxy and certificates
- Logging and observability
- Upgrade and rollback framework
- Initial platform API

## Phase 2 — PCI Understands PCI

- Engineering Knowledge Fabric implementation
- PCI architecture objects
- Relationship graph/query capabilities
- AI access to engineering knowledge
- Architecture/impact queries
- Automated knowledge validation

## Phase 3 — Knowledge and Intelligence

- Document/knowledge ingestion
- RAG and retrieval services
- Model/provider abstraction
- Agent framework
- Policy-aware tool execution
- Human approval workflows

## Phase 4 — Customer Zero

- Integrate the existing IT/Facilities/Biomedical helpdesk
- Network and infrastructure integrations
- Organizational knowledge integration
- Operational dashboards and proactive intelligence
- Validate security, reliability, usability, and deployment procedures in the real environment

## Phase 5 — Productization

- Customer deployment packages
- Tenant isolation model where required
- Marketplace/module packaging
- Upgrade lifecycle
- Installer and diagnostics
- Customer administration
- Support and observability model

## Phase 6 — Scale

- High availability
- Multi-site deployments
- Larger organizations
- Air-gapped deployment profiles
- Enterprise federation
- Expanded domains and connectors

## Roadmap Rule

A future capability may be designed early, but implementation should be sequenced according to architectural dependencies and customer value. Exciting ideas are recorded rather than allowed to destabilize the current milestone.
